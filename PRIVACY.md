# Политика конфиденциальности / Privacy Policy

_Действует для расширения «Контекстный переводчик» (Lingo Context), версия 0.1.3._

## Кратко

Расширение не имеет собственного сервера, не собирает аналитику и не передаёт данные
третьим лицам, кроме того сервиса перевода, который вы выбрали сами.

---

## Какие данные обрабатываются

| Данные | Где хранятся | Зачем |
|---|---|---|
| API-ключи провайдеров | `chrome.storage.local` (профиль браузера) | авторизация запросов к выбранному вами API |
| Настройки (языки, провайдер, глоссарий, списки сайтов) | `chrome.storage.local` | работа расширения между запусками |
| Кэш переводов | IndexedDB (`lingo-context`) | не оплачивать один и тот же текст дважды |
| Состояние перевода вкладки | `chrome.storage.session` (только память сеанса) | показывать прогресс в попапе |

**Ключи не синхронизируются** между устройствами: `storage.sync` не используется.
**Ключи не передаются никуда**, кроме запроса к API того провайдера, которому они
принадлежат.

---

## Какие данные передаются наружу

Только текст страницы, который нужно перевести, — и только в момент, когда вы нажали
«Перевести» (или сайт находится в вашем списке автоматического перевода).

Получатель:

- **выбранная вами модель** — DeepSeek, OpenAI, OpenRouter, Groq, Anthropic, Google Gemini,
  Ollama (локально) или ваш собственный шлюз;
- **выбранный вами бесплатный сервис** — Google Translate, MyMemory, LibreTranslate, Lingva
  или DeepL.

К запросу прилагаются: код языка источника и перевода, заголовок страницы, имя хоста,
контекст раздела и ваш глоссарий. Эти данные нужны, чтобы перевод учитывал контекст.
К ним применяются политики соответствующего сервиса — ознакомьтесь с ними, если текст
конфиденциален.

**Что не отправляется:** содержимое блоков кода, идентификаторы в инлайн-коде, URL, куки,
данные форм, содержимое вкладок, на которых вы не запускали перевод.

---

## Разрешения и зачем они

| Разрешение | Зачем |
|---|---|
| `storage` | хранить настройки, ключи, кэш |
| `activeTab` | применять перевод к открытой вкладке по вашему действию |
| `scripting` | внедрять контент-скрипт, если он не загрузился автоматически |
| `contextMenus` | пункты «Перевести страницу», «Перевести выделенное», «Сохранить в PDF» |
| `host_permissions` (адреса API) | отправлять запросы к сервисам перевода |
| `optional_host_permissions` | разрешить собственный шлюз, который вы укажете в настройках |

Расширение **не запрашивает** доступ к истории, закладкам, куки, данным форм, буферу обмена
и не читает страницы, на которых перевод не запускался.

---

## Ваши права

- **Удалить всё** — настройки → «Кэш и данные» → «Очистить кэш», затем удалить расширение.
- **Отозвать доступ** — удалите ключ в настройках провайдера или отзовите его на сайте
  сервиса.
- **Экспортировать настройки** — кнопка «Экспорт настроек» (ключи в экспорт **не** входят).

---

## Дети

Расширение не предназначено для детей и не собирает их данные осознанно.

# Privacy Policy (English)

Lingo Context has no backend, collects no analytics and shares nothing beyond the translation
service you choose.

- **Stored locally:** API keys, settings, translation cache (IndexedDB), per-tab progress
  (session memory only). Keys are never synced.
- **Sent to your provider:** only the page text you asked to translate, plus the source and
  target language, page title, host and your glossary. Code blocks, inline identifiers, URLs
  and cookies are never sent.
- **No tracking, no telemetry, no ads.**
- **Delete everything:** Settings → Cache & data → Clear cache, then remove the extension.
