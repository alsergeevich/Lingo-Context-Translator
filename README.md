# Контекстный переводчик (Lingo Context)

Расширение для Chrome, Яндекс Браузера и Opera, которое переводит веб-страницы **с учётом контекста**: текст переводит выбранная вами модель по вашему API-ключу либо бесплатный сервис перевода. Код, идентификаторы, команды и пути не переводятся никогда.

```
┌──────────────────────────────────────────────────────────────┐
│  страница  →  извлечение блоков  →  навык + промпт  →  API   │
│     ↑                                                    │   │
│     └──────── подстановка с сохранением ссылок ←─────────┘   │
│                          ↓                                   │
│                    «Оригинал» / PDF                          │
└──────────────────────────────────────────────────────────────┘
```

---

## Что умеет

| Возможность | Как это работает |
|---|---|
| **Перевод страницы целиком** | Кнопка в попапе, горячая клавиша `Ctrl+Shift+Y` или пункт контекстного меню. |
| **Перевод выделенного** | `Ctrl+Shift+U`-независимо: пункт меню «Перевести выделенное» показывает перевод во всплывающей карточке рядом с выделением. |
| **Язык источника** | Вручную или **автоматически**: скрипт письменности + стоп-слова, плюс встроенный детектор браузера, если он доступен. |
| **Язык перевода** | 26 языков, включая русский, английский, немецкий, китайский, японский, арабский. |
| **Модель по API-ключу** | DeepSeek, OpenAI, OpenRouter, Groq, Anthropic Claude, Google Gemini, Ollama/LM Studio (локально), любой OpenAI-совместимый шлюз. |
| **Бесплатные сервисы** | Google Translate (без ключа), MyMemory, LibreTranslate, Lingva, DeepL Free (с бесплатным ключом). |
| **Навык модели** | Отдельный версионируемый промпт: перевод с учётом контекста, запрет перевода кода, глоссарий, единая терминология. Редактируется в настройках. |
| **Код не переводится** | Блоки `pre`/`code` вообще не отправляются модели; инлайн-код и ссылки передаются как слоты `{{n}}…{{/n}}` и восстанавливаются байт-в-байт. |
| **Оригинал и перевод** | Кнопка «Показать оригинал» переключает всю страницу; режим «оригинал + перевод» показывает оба текста. |
| **PDF** | «Сохранить в PDF» открывает чистый печатный документ и диалог печати — выбираете «Сохранить как PDF». |
| **Кэш** | Уже переведённые фрагменты не оплачиваются повторно (IndexedDB, срок хранения настраивается). |
| **Сайты** | Список «переводить автоматически» и список исключений. |

## Установка

### Chrome

1. Соберите расширение (см. ниже) или скачайте `release/lingo-context-<версия>.zip` и
   распакуйте его в постоянную папку.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (справа сверху).
4. Нажмите **Загрузить распакованное** и выберите папку `dist`.

### Яндекс Браузер

1. Откройте `browser://extensions` (или «Настройки → Расширения»).
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → папка `dist`.

> Яндекс Браузер на Windows отключает расширения не из магазина при **каждом** перезапуске
> и сообщает об этом при старте — это его политика безопасности, а не ошибка расширения.
> Выключить проверку нельзя; чтобы расширение оставалось включённым, его нужно опубликовать
> в Chrome Web Store или Opera Add-ons ([подробнее](PUBLISHING.md)). Для разработки есть
> [бета-версия Яндекса](https://browser.yandex.com/beta/), в ней проверки нет.

### Opera

1. Откройте `opera://extensions`.
2. Включите **Режим разработчика** (справа сверху).
3. **Загрузить распакованное расширение** → папка `dist`.

> Расширение использует Manifest V3 и не содержит удалённого кода — требование Chrome Web
> Store. Все зависимости собираются локально, поэтому установка из папки работает во всех
> трёх браузерах одинаково.

### Сборка

```bash
npm install          # один раз
npm run build        # соберёт dist/
npm run verify       # типы + 140 тестов + сборка + сквозные проверки
```

Сборщик не требует esbuild/webpack: скрипт `scripts/build.mjs` транспилирует TypeScript и
собирает бандл сам, поэтому сборка работает даже в среде, где запрещён запуск
дочерних процессов.

## Быстрый старт

1. Установите расширение и откройте **Настройки**.
2. Вкладка **Переводчики** → выберите модель (например, DeepSeek) → вставьте API-ключ.
3. Нажмите **Проверить** — расширение отправит одну короткую фразу и покажет ответ.
4. Откройте любую страницу и нажмите **Перевести страницу**.

Ключ хранится только в `chrome.storage.local` вашего профиля. Он не синхронизируется и
никогда не покидает компьютер, кроме запроса к выбранному вами API.

## Навык модели

Главное требование задания — перевод «с учётом контекста» — реализовано как отдельный
**навык** (`src/core/skill/translation-skill.ts`), который отправляется модели с каждым
запросом. Он задаёт:

- **что нельзя трогать**: код, идентификаторы, флаги CLI, пути, URL, версии, плейсхолдеры,
  числа, регулярки, разметку;
- **как учитывать контекст**: домен документа (документация, статья, юридический текст,
  магазин, форум), заголовок раздела, окружающий абзац, единая терминология на странице;
- **слоты `{{n}}…{{/n}}`**: ссылки и инлайн-код остаются живыми элементами страницы;
- **формат ответа**: ровно один блок `[id] текст` на каждый фрагмент, без пояснений.

Полный текст виден на вкладке **Навык модели** в настройках. Там же можно добавить
собственную инструкцию или заменить встроенный навык целиком.

Версия навыка (`SKILL_VERSION`) входит в ключ кэша: после изменения промпта старые
переводы не используются.

### Пример: страница с кодом

Оригинал:

```
The `use_signal` hook returns a `ReadOnlySignal<T>`, so the value can be cloned cheaply.
Run cargo build --release to produce an optimized binary.
```

Модель получает `{{0}}{{/0}}` вместо `use_signal` и `[1]`-идентификаторы вместо блоков
кода, поэтому даже при плохом качестве перевода идентификаторы и команды остаются
неизменными — их просто нет в промпте.

## PDF

Сохранение идёт через системный диалог печати — это единственный способ, который работает
одинаково в Chrome, Яндекс Браузере и Opera без специальных разрешений. Расширение
формирует отдельный документ:

- заголовок, адрес страницы, дата, языки и провайдер;
- аккуратная типографика, светлая тема независимо от темы сайта;
- блоки не разрезаются между страницами, код сохраняется как есть;
- опционально — оригинал под каждым переведённым фрагментом.

В диалоге печати выберите принтер **«Сохранить как PDF»**.

## Приватность

- Нет собственного сервера: перевод идёт напрямую в выбранный вами сервис.
- Ключи хранятся локально в профиле браузера и не синхронизируются.
- Кэш переводов лежит в IndexedDB и удаляется одной кнопкой.
- Расширение не собирает аналитику и не отправляет телеметрию.
- Подробнее — [PRIVACY.md](PRIVACY.md).

## Ограничения и честные предупреждения

- **Google Translate без ключа** использует неофициальный публичный эндпоинт: он может
  ограничивать частоту или измениться. Для стабильной работы выбирайте модель с ключом.
  Остальные бесплатные сервисы (MyMemory, LibreTranslate, Lingva) — тоже best-effort.
- **Бесплатные сервисы не учитывают контекст**: навык к ним не применяется, поэтому
  качество терминологии ниже. Ссылки и инлайн-код они всё равно не портят — защита
  встроена в расширение.
- **Стоимость**: каждая страница — один или несколько запросов к модели. Размер порции и
  кэш позволяют её контролировать.
- **Динамические страницы**: переводятся блоки, существующие на момент запуска. Для
  бесконечной прокрутки запустите перевод ещё раз после прокрутки.
- **Защищённые страницы** (`chrome://`, магазины расширений, PDF-просмотрщик) переводить
  нельзя — это ограничение браузера.

## Структура проекта

```
src/
  background/     service worker: маршрутизация сообщений, кэш, меню, команды
  content/        извлечение текста, слоты, подстановка, панель, выделение, PDF
  core/
    providers/    адаптеры провайдеров (OpenAI-совместимые, Anthropic, Gemini, MT)
    skill/        навык перевода, примеры, валидатор ответа
    cache.ts      IndexedDB-кэш переводов
    lang-detect.ts определение языка
    translator.ts оркестратор: кэш → провайдер → результат
  popup/          попап
  options/        настройки
  print/          печатный документ для PDF
  shared/         типы, языки, настройки, сообщения, строки интерфейса
tests/            140 юнит-тестов
tools/            сквозные проверки (бандл, реальная страница, UI)
scripts/          сборка, тесты, проверка кодировки
```

Подробное описание решений — [ARCHITECTURE.md](ARCHITECTURE.md). Публикация в магазины
(Chrome Web Store, Opera Add-ons) и что делать с отключением в Яндекс Браузере —
[PUBLISHING.md](PUBLISHING.md).

## Проверки

```bash
npm run verify
```

| Шаг | Что проверяет |
|---|---|
| `typecheck` | строгая типизация всех исходников |
| `unit tests` | 140 тестов: навык, валидатор, извлечение, слоты, настройки, кэш-ключи, язык, маркеры слотов, кодировка |
| `build` | сборка пяти бандлов |
| `bundle e2e` | собранный service worker в Node с мок-API Chrome и живым HTTP-моком DeepSeek |
| `dom e2e` | реальная страница `book.leptos.dev` в jsdom: 70 блоков кода остаются неизменными, откат восстанавливает DOM побайтово |
| `ui smoke` | попап и все 8 вкладок настроек в jsdom, включая кнопку «Проверить» |
| `encoding` | отсутствие «кракозябр» в исходниках |

Проверка на живом Chrome недоступна в этой среде (запрещён запуск процессов), поэтому
браузерный уровень покрыт прогоном настоящего бандла в Node с мок-API Chrome и настоящей
страницы в jsdom.
